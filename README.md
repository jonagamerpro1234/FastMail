# FastMail
Programa simple para enviar correos desarrollada en Python, Tkinter y PyWhatKit

## Caracteristicas
- Interfaz Grafica simple
- Envío de correos mediante servidores SMTP de Gmail (Solo acepta Gmail por ahora)
- Mensaje de Exito o Error respectivamente

## Requisitos

- Python 3.x
- Cuenta de Gmail con verificacion de 2 pasos activada

## Dependencias
```bash
python -m pip install -r requirements.txt
```
